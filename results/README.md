# Results
 
This folder stores all outputs generated during the analysis and model development.
 
## Contents
 
| File | Description |
|------|-------------|
| `summary_statistics_JFM_2025.csv` | Descriptive statistics of the January–March 2025 dataset |
| `correlation_matrix_JFM_2025.csv` | Correlation matrix of Tg and the predictor variables |
| `correlation_heatmap_JFM_2025.png` | Heatmap of the correlation matrix |
| `MLR_variable_selection_JFM_2025.csv` | Performance of the 15 MLR predictor combinations on the validation set (80/20 random split, seed 90) |
| `MLR_3vars_plot.png` | Observed vs. estimated Tg, three-variable MLR (T, W, SR), validation set |
| `RF_3vars_plot.png` | Observed vs. estimated Tg, three-variable RF (T, W, SR), validation set |
| `model_comparison_3vs4_variables.csv` | Summary of the four models (RF and MLR, with three and four variables): validation split, GroupKFold cross-validation, WBGT error metrics, and independent January 2026 evaluation |
 
All files in this directory are automatically generated by the notebooks contained in the `analysis` folder.
 
## Note
 
The notebook `analysis/training_test_analysis_2models.ipynb` also exports four trained models (`RF_3vars_JFM_2025.pkl`, `MLR_3vars_JFM_2025.pkl`, `RF_4vars_JFM_2025.pkl`, and `MLR_4vars_JFM_2025.pkl`). They are not included in this repository, but can be reproduced by running the notebook (random seed 90). Interested users may contact the corresponding authors.
