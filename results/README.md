# Results

This folder stores all outputs generated during the analysis and model development.

The contents include:

- Figures generated during exploratory analysis and model evaluation.
- Correlation matrices and descriptive statistics.
- Scatter plots comparing observed and predicted globe temperature (Tg).
- Regression plots and performance visualizations.
- Cross-validation and external validation results.
- Any additional tables or graphics produced throughout the analysis.

All files in this directory are automatically generated by the notebooks contained in the `analysis` folder.

---

## Note

The trained Random Forest (`.pkl`) model is not included in this repository. The model can be reproduced by running `analysis/training_test_analysis.ipynb`, which automatically trains the model and exports the serialized file. Interested users may contact the corresponding authors.
