# Data

This folder contains the datasets used to train and evaluate the machine learning models developed in this study.

## Files

- `JFM_2025.csv` — Dataset used for model training and internal validation.
- `JAN_2026.csv` — Independent dataset used for external model evaluation.

## Data preprocessing

Before being included in this repository, both datasets were preprocessed to retain only observations collected between **10:00 AM and 4:00 PM**, corresponding to the period of greatest solar exposure and heat stress.

The datasets are already cleaned and formatted, making them directly suitable for exploratory analysis, model training, validation, and performance evaluation.
